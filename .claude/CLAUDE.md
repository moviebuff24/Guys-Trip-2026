# Guys Trip 2026

## What this is
Planning tools for Joe's Aug 7–10, 2026 houseboat trip on Lake Cumberland (Kentucky, State Dock Marina) with a group of friends from Ann Arbor.

## Live site
- **URL:** https://moviebuff24.github.io/Guys-Trip-2026
- **Repo:** `github.com/moviebuff24/Guys-Trip-2026`, GitHub Pages

## Key files
- `guys-trip-comparison.html` — the original 4-option trip comparison matrix
- `ky-houseboat.html` — detail page for the picked option (the houseboat), itinerary, and booking checklist
- `lake-map.html` — interactive Leaflet map with day-by-day stops, water-following routes, coves/waterfalls/dining pins
